# Удалённая установка киоска из админки

В админке на странице **Киоски** можно указать hostname ПК и поставить галочку **«Установить софт на ПК»** (или нажать **Установить** у уже добавленного).

Сервер по **WinRM** подключается к ПК, копирует один `package.zip` (через шару `C$` или WinRM), распаковывает в `C:\ProgramData\StellaKiosk\`, пишет `kiosk.json`, поднимает агент (UI + health) и открывает Edge в kiosk-режиме.

## Подготовка сервера (один раз)

1. В `.env`:

```env
SERVER_PUBLIC_URL=http://192.168.1.10:8080
DEPLOY_USER=DOMAIN\admin
DEPLOY_PASSWORD=...
```

`SERVER_PUBLIC_URL` — адрес API, доступный киоскам в LAN.

2. Собрать пакет:

```powershell
pnpm pack:kiosk-deploy
```

Опционально: portable Node в `tools/node/node.exe` (иначе на киоске должен быть Node в PATH).

3. На **киоск-ПК** должен быть включён WinRM (в домене обычно уже есть):

```powershell
Enable-PSRemoting -Force
```

Firewall: разрешить WinRM с сервера Stella; на киоске входящий **47821** (health).

4. Перезапустить API (`pnpm start:prod`), чтобы подтянуть `.env`.

## Использование

1. Админка → Киоски.
2. Hostname, например `patriotstela1`.
3. Галочка «Установить софт на ПК» → Добавить.
4. Статус колонки **Установка**: ставится → установлен / ошибка.
5. Привяжите экспонат.

## Что оказывается на ПК

| Путь | Назначение |
|------|------------|
| `C:\ProgramData\StellaKiosk\` | Агент, UI, `kiosk.json` |
| Задача `StellaKioskAgent` | Автозапуск агента (health :47821, UI :47820) |
| Задача `StellaKioskUI` | Edge kiosk → `http://127.0.0.1:47820/` |

## Типичные ошибки

| Сообщение | Что сделать |
|-----------|-------------|
| Нет пакета установки | `pnpm pack:kiosk-deploy` |
| WinRM / Access denied | `DEPLOY_USER`/`DEPLOY_PASSWORD`, права админа на ПК |
| Долго на «Копирование» | Раньше копировали дерево Node через WinRM. Сейчас один zip (~30 MB) через `C$`; при блокировке SMB — fallback WinRM (дольше, но не зависает на тысячах файлов) |
| SMB / admin share | На киоске: File and Printer Sharing, порт **445**; скрипт пробует IP (через WinRM), `hostname.udhb.local`, затем короткое имя. Если SMB закрыт — копирование идёт через WinRM (медленнее, это нормально) |
| Отмена установки | В админке кнопка «Отменить» во время `queued`/`running` — останавливает PowerShell (`taskkill /T`) |
| Запуск киоска | Кнопка «Запустить» поднимает агент и открывает Edge **в сеансе пользователя за консолью** (не через Session 0 WinRM). Если на ПК никто не вошёл — агент стартует, а экран нет: войдите на киоск (или автологон) и нажмите «Запустить» снова |
| Node.js не найден | `tools/node` или установить Node на киоск |
| Хост не резолвится | DNS / имя ПК в домене |
