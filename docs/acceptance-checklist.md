# Чеклист приёмки MVP

По §14 [ТЗ](TZ-informacionnye-kioski.md).

- [ ] Администратор создаёт экспонат с текстом, фото, галереей и видео и привязывает киоск.
- [ ] Киоск с корректным `kioskId` после синка показывает экспонат без переустановки приложения.
- [ ] Разделы UI: главная, описание, галерея (листание), видео — работают на 1920×1080 (сенсор).
- [ ] При остановке сервера киоск показывает последний закэшированный контент.
- [ ] Idle бездействия возвращает на главный экран.
- [ ] Через UI киоска нельзя открыть проводник / сменить экспонат / попасть в админку.
- [ ] Assigned Access на Windows Pro: посетитель не выходит на рабочий стол штатными жестами.
- [ ] В админке виден мониторинг: онлайн/офлайн, последний контакт, версия контента, статус синка, привязка.
- [ ] Роли: `viewer` не меняет контент; `editor` не управляет пользователями; `admin` — полный доступ.
- [ ] Сценарий ~25 киосков × ~25 экспонатов обслуживается в LAN (CRUD, sync, мониторинг).
